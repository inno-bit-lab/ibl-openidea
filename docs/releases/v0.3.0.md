# IBLOpenIdea 0.3.0

Draft release notes. The coordinator finalises them with the release candidate.

IBLOpenIdea 0.3.0 is rebuilt on OpenIDEA `504d859` (v0.1.29 plus five fixes). Where OpenIDEA now has its own version of a feature the fork had built, 0.3.0 uses OpenIDEA's. The fork keeps only what OpenIDEA lacks, plus its brand and profile migration.

## Before you upgrade

- The updater signing key has changed (new key ID `A31A0E471F28FEEC`). Installs of 0.2.0 and 0.2.1 trust the old key and cannot update on their own: install 0.2.2 or later manually once. From 0.2.2 on, Check for Updates works again.
- Since 0.2.3 IBLOpenIdea keeps its profile under its own identifier, `it.innobitlab.iblopenidea`, instead of OpenIDEA's `ai.l0ng.openidea`.
  - If 0.2.3 is installed, 0.3.0 uses that profile as it is.
  - If you come from 0.2.2 or older, the first start copies your settings, recent projects, agents, local history, scratches, plugins and tools from the `ai.l0ng.openidea` folders. Nothing there is moved or deleted, so an installed OpenIDEA keeps working. Caches, indexes, language servers and logs are rebuilt instead of copied. On Windows, if OpenIDEA is running during that first start, its WebView data (layouts and presets) is skipped and a one-time notification says so.

## New from OpenIDEA

- Native Claude Code and Codex drivers, ACP v2 and the ACP Registry, where you install, update and remove agents (Settings › Tools › Agents).
- A Git tool window that works across several repositories.
- A GitHub pull requests tool window with the timeline and the review flow. It lists every open pull request by default.
- Jupyter notebooks, with native editing and execution.
- Font pickers that list every installed font family, with an editable font search.

## Italian

The interface is available in Italian. Choose "Italiano (Italian)" in Settings › System Settings › Language and Region.

## Kept from IBLOpenIdea

- Commit message suggestion with an agent, read-only as in 0.2.2. It is now in both the Commit tool window and the modal Commit dialog.
- Agent presets, injected instructions, and custom arguments and enable/disable per agent.
- Show History for Selection and Show Current Revision.
- Show Ignored Files in the Commit view.
- The two-pane Compare Branches editor.
- A repository picker in the Pull, Merge, Rebase, Manage Remotes, Worktrees and Stash dialogs, with the remotes grouped by repository. Update and Push can be scoped to one repository or a subset.
- In a folder of repositories that sits inside another repository, the outer repository is left out.
- Dialogs never grow past the window, and long messages scroll.
- The IBLOpenIdea brand and the profile migration.

## Replaced by OpenIDEA's version

These fork features are gone, and OpenIDEA's versions take their place:

- The branch tree that merged the same branch name across repositories is replaced by OpenIDEA's tree, grouped by repository.
- The Roots filter of the Git log is replaced by OpenIDEA's Repository filter.
- "Select in Tree…" in the log's path filter is replaced by OpenIDEA's Paths filter.
- Tag and Reset no longer ask which repository to use.
- Cherry-pick runs in one repository at a time, because a log selection stays inside one repository.
- The fork's graph layout for several repositories is replaced by OpenIDEA's.
- "Compare with Revision…" is replaced by OpenIDEA's "Compare with Branch or Revision…".
- The fork's History tab is replaced by OpenIDEA's history tab in the Git log.
- The built-in agy and pi agents are replaced by "Google Antigravity" (`antigravity-acp`) and "pi ACP" (`pi-acp`) from the ACP Registry. Saved settings and presets that name agy or pi are moved to the new ids.

## Behaviour changes

- Update Project runs at once with the configured update method. To get the options dialog back, turn on "Show options before Update" in Settings › Version Control › Confirmation. If you had saved that option, your choice stays.
- Commit message suggestion reads the latest commit subjects from the repository selected in the Git tool window.
- Codex and Claude Code now start through the native `codex` and `claude` command-line tools. If you used them only through the npx adapter, without those tools on your PATH, the agents named "Codex" and "Claude Code" no longer start for you, and a commit suggestion agent set to Codex stops working. Your custom arguments move to "Codex (ACP)" and "Claude Code (ACP)".
- If your 0.2.x Codex or Claude configuration set environment variables or a custom name, they are kept in a "Codex (ACP)" or "Claude Code (ACP)" configuration file. That file takes the place of the built-in entry, so it stays on the adapter version 0.2.x used and does not follow later updates.
- Environment variables set for agy or pi in 0.2.x are not carried over. The old files remain next to the agent configuration as `agy.toml.v02` and `pi.toml.v02`.
- Agent tasks started in 0.2.x with agy or pi cannot be resumed. The app shows an error instead.
- The app now adds to PATH only the tool folders that exist. On Windows this keeps PATH much shorter: past cmd.exe's limit of 8,191 characters, tools started through `.cmd` shims, such as the native Codex and npx agents, could not find `node`. Language servers and debuggers installed from Settings still start on the next file open, without a restart. The terminal, run configurations and agents see a newly installed tool only after a restart. If PATH still goes past 8,191 characters on Windows, the log records a warning.

## Known limitations

- Files copied from an old `ai.l0ng.openidea` profile can still contain absolute paths into that folder. They keep working, because the migration never deletes the old folder.
- These checks are pending at the time of writing: updating a 0.2.x install to the release candidate through the updater, commit message suggestion with native Claude Code and Codex on a real machine, and the Git tool window on a folder of repositories (History for Selection, Show Ignored Files, two-pane Compare, repository pickers).
