## 3. Solution design

See spec 5.1 to 5.6. Interfaces fixed here:

- `ide_agent::AgentPaths.managed_agents_dir: Option<PathBuf>` and `ide_host::HostConfig.managed_agents_dir: Option<PathBuf>`. `src-tauri/src/state.rs` sets it to `dirs::data_local_dir()/<app identifier>/acp-agents`; `openidea-server` (`crates/ide-host/src/bin/server.rs`) sets `<server home>/data/acp-agents`.
- `fn agy_search_roots(managed: Option<&Path>, home: Option<&Path>, exe_dir: Option<&Path>) -> Vec<PathBuf>` in `provider.rs`: pure, used by `find_agy_acp_server`. No `C:\Users` walk, no hard-coded identifier.
- `fn restrictive_mode(options: &[AgentConfigOption]) -> Result<String, String>` in `crates/ide-agent/src/lib.rs`: finds the option whose `id` or `category` is `mode`; returns the first of `read-only`, `read_only`, `default` among its values; `Err` naming the available values when there is no mode option or no allowlisted value. `complete` applies it to the options the agent reports, falling back to `known_config`, and sends the result as an `AgentConfigChoice { id: "mode", .. }` ahead of the caller's choices. The error shown to the user: `<agent name> cannot run read-only (modes: <values>). Choose Claude, Codex or Antigravity for commit suggestions.`
- `complete` runs in `std::env::temp_dir()/ibl-suggest-<uuid>`, created empty and removed after the call; a removal failure is logged, not returned.
- New command `vcs_ignored() -> Vec<FileStatus>` (ignored entries only): `crates/ide-host/src/ops/vcs.rs` (`pub async fn ignored`), registered in `crates/ide-host/src/rpc.rs` next to `vcs_status` and as a Tauri command in `src-tauri/src/commands/vcs.rs` plus `collect_commands!` in `src-tauri/src/commands/mod.rs`. `vcs_status` returns `repos.status()` again.
- `deleteInRepos(name, roots, opts?: { confirm?: boolean })`, `deleteRemoteInRepos(name, roots, opts?)`, `deleteRemoteBranch(name, repo, opts?)`: `confirm` defaults to `true`.
- `CustomAgent`: `command` becomes `Option<String>` (`serde(default)`), new `extra_args: Vec<String>` (`serde(default, skip_serializing_if = "Vec::is_empty")`). For a built-in id without `command`, `load` uses the built-in's command and args and appends `extra_args`. A non-built-in id without `command` is rejected with a clear error. `deny_unknown_fields` stays.
- `GitOperationOptions.repo?: string | null`; `runGitOperation` uses `opts.repo ?? currentRepo()`.
