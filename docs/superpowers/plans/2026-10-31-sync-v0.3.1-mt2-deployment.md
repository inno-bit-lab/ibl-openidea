- MT-1 already changed host RPC tests/ops registration and Tauri command registration. Retain JVM presentations, all fork agent/VCS registrations and new deployment operations. Regenerate bindings; do not use whole-file upstream versions that lose MT-1.

- Preserve default SFTP deserialization for existing saved server settings, local folder validation and current remote-dev run-target distinctions. Do not confuse a local deployment server with an SSH development host.
