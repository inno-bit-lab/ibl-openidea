- `CommitView.tsx` adds getDirectory only. Preserve Suggest request generation, cancellation/unmount/draft-change guards, current-repo selection and updateBeforeCommit=false in TS/Rust preferences. `commitStore.ts` upstream changes selectedShelf comment; no default reset.
- `controller.ts` disk sync and editor actions coexist with fork selectionLineRange/history-for-selection/current-revision menus. `Tree.tsx` keeps detail tooltip; no reintroduction of the reverted horizontal-overflow CSS. `icons.tsx` retains agy/pi plus MT-1 JVM icons.
- Settings schema/behavior/custom scheme changes retain LocaleId/LOCALES it and all workflow preferences. `colorScheme.tsx` retains IBLOpenIdea SAMPLE text while importing/exporting custom schemes. New scheme text is global, not project-defined executable configuration.
- Host project/RPC/Tauri registrations already changed in MT-1/MT-2; retain every accepted command. Regenerate bindings after TextEncoding/native-to-ascii settings and disk-sync command changes. No Cargo manifests/lockfile update expected in this tranche.
- Catalog keys merge additively with previous tranches; remove Copy Patch to Clipboard only after all source uses migrate to Copy as Patch to Clipboard. Do not restore stale fork-removed Direction/In {left}, not in {right} or upstream product labels.

Encoding invariants: setting is default-off; clean buffers may reload when changed, dirty ones retain their codec; eligible escapes/surrogate pairs round-trip, malformed/unpaired/line-terminator escapes remain literal, and unchanged/undone saves preserve bytes. Search, unopened readers, Git diff/staging/partial commits must agree on the same codec.

Disk-sync invariants: debounce focus events, reload clean changed documents, preserve dirty content with existing conflict warning, refresh tree/VCS, keep cheap metadata checks for unchanged docs. Shelf invariants: selected file operations affect only that file, use saved base, and cover added/deleted/binary/quoted paths.
