# v0.3.1 release notes: inputs for MT-7

Collected by the coordinator from the tranche deliveries and reviews (2026-10-31 and 2026-11-01). This is input for `docs/releases/v0.3.1.md`, not the release notes themselves. Each item names its source so MT-7 can check it.

## New and changed for users

- **Upstream sync to v0.1.31** (`06109aae`), tranches MT-1 to MT-6 below.
- **Windows: agent process trees end with the agent** (#14, #18). Closing or cancelling an agent task, a probe or a commit suggestion now ends every process the agent started. This includes dev servers, watchers and build daemons started by an agent, unless they break away from the job. It fixes the locked `ibl-suggest-*` folders and the orphaned Antigravity processes seen with v0.2.x. Unix: unchanged.
- **Windows: progress window on the first start after updating from v0.2.x** (#17, #18). Text proposed by dev-codex: "On Windows, the first start after updating from v0.2.x shows a progress window while IBLOpenIdea copies your profile. It appears once and closes by itself; do not end the app while it is shown." macOS and Linux keep the current behaviour.
- **MT-1, JVM, Go, C/C++ and LSP** (#15): richer JVM project icons; core Go workflows; CMake targets run and rename works through file aliases; the Tomcat WAR comes from the selected Maven module; jdtls access restrictions are warnings; the Java debugger shows startup progress and can be cancelled; Services shows debug session output and state.
- **MT-2, deployment** (#16): deploy to a local or mounted folder; the server picker shows only servers that cover the selected paths. Fork fixes: deleting a folder keeps excluded descendants; selecting a folder that contains mappings covers them.
- **MT-3, editor, search, console, shelf** (#19): import and export editor colour schemes (IntelliJ `.icls`); in-file Find results open in the Find window; shelved changes show per file with per-file actions; search in the console output; Find in Files uses the focused folder; preview layout controls move into the tab strip; the scratch language search field is visible; the terminal keeps focus after its context menu.
  - External file changes are synchronized when the IDE window regains focus, **on by default**, with an opt-out in Settings (#564).
  - Transparent native-to-ascii for `.properties` is **off by default** (#537). When it is on, escapes of `=`, `:`, `#`, `!`, whitespace and backslash stay spelled out in the editor, so saving never changes keys or turns lines into comments (fork deviation).
  - Fork fixes: a shelf with `file.bin` and `b/file.bin` no longer loses the sibling's change; console search no longer hangs on an empty match before an emoji.
- **MT-4, shell and menu** (#21): frameless title bar on Linux (title IBLOpenIdea); the Settings window stays inside the work area on Windows and Linux; new option to merge the main menu into the toolbar. Fork fix: keyboard focus is kept when the merged menu collapses to the hamburger.
- **MT-5, ARM** (#20): Windows ARM64 and Linux ARM64 downloads. The updater follows the installed build: an x64 install on an ARM machine keeps receiving x64 builds, and switching to ARM64 needs a manual install. On Windows ARM64, native tools and agents come first (native, then npx, then uvx, then emulated x64). TO CHECK before writing: x64 emulation on ARM may exist only on Windows 11 (Windows 10 on ARM emulates x86 only); source needed.
- **MT-6, project trust** (#22): a project opens in Restricted Mode until the user trusts it. Project-controlled execution (Git executable/filters/hooks, terminal startup commands, runs, agents) waits for trust; reading and editing work.
  - Without a `project-trust.json`, recent projects are trusted on the first start (migrated profiles too).
  - Commit Suggest is unavailable in Restricted Mode; revoking trust or closing the project cancels a running suggestion.
  - The agent catalog and agent arguments stay available without a project or trust (they only touch the user's profile).
  - Remote development uses protocol 2: an older `openidea-server` is incompatible; the app downloads the matching server.
- **D3, Suggest structured result** (pending at the time of writing): Suggest accepts only a structured answer; an agent error is shown as an error and the draft is kept.

## Known limitations

- Antigravity 1.4.5 may not answer the ACP `initialize` within 30 seconds on some machines (seen with and without the teardown fix).
- Pi: provider errors (for example an exhausted credit) are hidden by the `pi-acp` 0.0.34 adapter, which reports a failed prompt as a normal end of turn; no fixed adapter version exists yet.
- Windows "Installed apps" may keep showing the previous version after an in-app update (seen 0.2.2-2 -> 0.2.3-2); cause under investigation.
- Rare trust races: a trust grant concurrent with a revoke or a close can leave the agent admission flag out of step with the project's trust (rev-claude review 62ECD6); follow-up.
- If a previous profile copy failed, the cleanup on the next start shows no progress window (rev-claude review AA3839).
- Desktop checks still NOT_VERIFIED in CI (owner checklist v0.3.1): the migration dialog look, focus and scaling; the merged menu with real controls and Italian labels; Settings on scaled or secondary monitors; the trust prompt and Suggest disabled in the real GUI; native Codex revoke with directory removal; a real remote host on protocol 2; ARM installers and updater runtime.
